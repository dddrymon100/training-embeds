AI Drafting in Scripture Forge

Learn how to make an AI draft of a Bible book, and how to put it into Paratext.

About 15 minutes. Three short lessons and a quiz.

You will learn how to

  • Log in and connect your project to Scripture Forge.
  • Get your project ready and start a new AI draft.
  • Add the finished draft to Paratext, or download it.
  • Protect the work that is already in your Paratext project.

Before you start

Make sure you have:

  • A Paratext login.
  • Administrator access to your Paratext project.
  • Permission to edit the book you want to draft.

Lesson 1 of 3

Log in and connect

First, log in to Scripture Forge. Then connect your project.

  1. Log in to Scripture Forge with your Paratext login.

    Remember: You must have Administrator access to the project to make a new AI draft.

  2. Open the project you want to use for AI drafting.

  3. Look at the button next to your project.

    • If you have not made an AI draft in Scripture Forge before, select Connect. The project must be ready for AI drafting.
    • If you only see Join, you need Administrator access. Ask for Administrator access to the Paratext project.

Lesson 2 of 3, part 1 of 3

Get your project ready

Before you make a draft, update your project data. Then check your sources.

  1. In Paratext, open the project you want to draft in. Run a Send/Receive. This makes sure Scripture Forge uses the newest project data.

  2. In Scripture Forge, select the Paratext project you want to draft in. Then select Sync with Paratext at the bottom left of the screen.

  3. Open the Generate Draft page. Select Configure sources. Check two things:

    • The correct primary reference project is listed.
    • The same project is selected as the source.

Lesson 2 of 3, part 2 of 3

Start a new draft

Now you will set up your draft. Take your time with each check.

  1. Select the Generate draft tab again. Then select + New Draft.

  2. Check the setup page. The References and Drafting from sources must match. To change them, select Change source configuration.

    Also check that your translation project is listed as the project you want to make a draft for.

  3. Choose the book you want to draft.

    Draft one book at a time. The AI model keeps learning from your team’s final translation choices. This helps the draft of the next book.

Lesson 2 of 3, part 3 of 3

Train and generate

Choose the books that teach the AI model. Then start your draft.

  1. Choose the books for training. Select all the books that have translated text in your project. Also select all of the Reference Books.

    A solid line under a book name shows if the book has translated text, and how much.

  2. Do a final check. Make sure all of the information is correct. To make a change, go back to an earlier step. When everything is correct, select Generate Draft.

  3. Wait for your draft. The first AI draft can take up to 2.5 hours.

    You do not need to keep your computer on or connected to the internet. The draft is made on a server, not on your computer.

Lesson 3 of 3, part 1 of 2

Use your finished draft

When your draft is ready, you have two choices. You can add it to a Paratext project, or you can download it.

Choice 1: Add the draft to a Paratext project

This takes two steps. First, you apply the draft in Scripture Forge. Then you sync it to Paratext.

Before you start: Check that the book is empty in the Paratext project. Any translated text in that book will be deleted by this sync.

  1. Go to the Generate draft page.

  2. Look at the Formatting options.

  3. Select Add to a Project.

  4. Select the project you want to add the draft to. To see your projects, select the project name. A list of your Paratext projects will open. Then select Next.

  5. Sync to Paratext.

Choice 2: Download the draft

Use this choice if you do not want to send the draft to Paratext.

  1. Go to the Generate draft page.

  2. Select Download draft. The draft downloads to your computer as a zipped file.

Lesson 3 of 3, part 2 of 2

Protect your work

An AI draft deletes any text that is already in the Paratext book.

If you send an AI-drafted book to a Paratext project that already has content, the draft deletes the existing material.

If the Paratext book has any content, send the AI draft to a different Paratext project.

Check these things first

  • Is the book empty in the Paratext project? If it is not, choose a different project.
  • Do you have Administrator access to the project?
  • Do you have permission to edit every book you will draft in Paratext?

Review

Key points to remember

  • Log in with your Paratext login. You need Administrator access to make a new AI draft.
  • Before you draft, run Send/Receive in Paratext. Then select Sync with Paratext in Scripture Forge.
  • Check your sources. The References and Drafting from sources must match.
  • Draft one book at a time. Select the training books and the Reference Books.
  • The first draft can take up to 2.5 hours. You do not need to keep your computer on.
  • Add the draft to an empty Paratext book, or download it. Never send a draft to a book that has text you want to keep.
